# Marketing A/B Testing & Conversion Analysis

## 📌 Project Overview

This project analyzes marketing A/B testing data to compare conversion performance between test groups and evaluate campaign effectiveness using statistical analysis.

## 🎯 Objectives

* Analyze user and conversion behavior across test groups
* Calculate and compare conversion rates
* Test whether the observed conversion difference is statistically significant
* Generate business insights from the analysis

## 🛠️ Tools & Technologies

* **Python**
* **Pandas & NumPy**
* **Jupyter Notebook**
* **Matplotlib**
* **Statistical Analysis**
* **Power BI**

## 🔍 Analysis Performed

* Data loading, cleaning, and exploration
* Hypothesis formulation
* Conversion rate analysis
* Data visualization
* Z-test for statistical significance
* 95% Confidence Interval analysis
* Business conclusion

## 📊 Power BI Dashboard

The project includes an **Executive Overview Dashboard** featuring:

* Total Users
* Ad Users
* Ad Conversions
* Conversion Rate Difference
* Conversion Rate by Test Group
* Users by Test Group
* Average Ads Seen
* Daily Conversions
